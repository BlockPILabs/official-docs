# allMids

#### Parameters

| Name | Type   | Required | Description |
| ---- | ------ | -------- | ----------- |
| type | String | Yes      | `"allMids"` |

#### Returns

**Object** - Key-value pairs of coin name to mid-market price (String). If the order book is empty, the last trade price is used as a fallback.
