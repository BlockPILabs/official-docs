# Legacy Endpoints

Starting from November 2026, the new version of the dashboard supports enabling multiple networks with a single key. Therefore, legacy keys will be consolidated under the "History migration key" subpage. Please note that these keys are still valid, but we strongly recommend that users switch to the new keys for sending requests.
