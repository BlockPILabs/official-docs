# elysium

> Elysium is an Arbitrum Orbit chain (Chain ID: 99901 / 0x1863d). It is fully EVM-compatible and runs on the Nitro execution client (`nitro/v3.12.2`).

BlockPI supports the following JSON-RPC methods for the Elysium network. All requests should be made to:

```
https://elysium.blockpi.network/v1/rpc/your-rpc-key
```

{% hint style="info" %}
The block range of `eth_getLogs` is limited to **1024** for public endpoints and **5000** for private endpoints. Requests with blocks over this range will get an error.
{% endhint %}
